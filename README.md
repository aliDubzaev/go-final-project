это веб-приложение для управления задачами.
Программа позволяет добавлять, редактировать, выполнять и удалять задачи, а также поддерживает повторяющиеся события (ежедневные, еженедельные и т.д.).

Проект написан на Go, использует SQLite для хранения данных и имеет встроенный веб-интерфейс.

Реализован Dockerfile для сборки и запуска веб-сервера в контейнере.

Запуск проекта локально

1. Клонируйте репозиторий:

        git clone https://github.com/aliDubzaev/go-final-project.git
        cd go-final-project

2. Запустите сервер:

        go run main.go


3. Откройте приложение в браузере:

        http://localhost:7540

Запуск тестов

1. Проверьте, что сервер запущен локально (порт 7540).

2. Запустите тесты:

        go test ./tests

Запуск через Docker

1. Сборка образа

        docker build -t go-scheduler .

2. Запуск контейнера

        docker run -d -p 7540:7540 -v $(pwd)/data:/data go-scheduler

3. После запуска приложение будет доступно по адресу:
        
        http://localhost:7540

Структура проекта

        go-final-project/
        ├── pkg/
        │   ├── api/              # HTTP-обработчики
        │   ├── db/               # Работа с SQLite

        ├── web/                  # Файлы фронтенда
        ├── tests/                # Автоматические тесты
        ├── scheduler.db          # SQLite база данных

        ├── go.mod                # Модуль Go
        ├── main.go               # Точка входа
        └── README.md             # Документация проекта
